Making RSVPs Fun Again

InByte transforms the boring "Do you want to go out?" text message into a highly interactive, personalized web experience.

✨ The Project

Asking someone out on a date should be memorable. This project was born out of a desire to create a playful, creative way to invite someone to the movies.

Every digital invitation features:

  • Interactive Themes: Visuals and animations perfectly matched to the movie choice, from Marvel web-shooters to Doctor Doom portals.
  • The "Runaway" No Button: A cheeky UI element that playfully dodges the user's cursor while taunting them, making it practically impossible to say no!
  • Unique Experiences: Every invitation is packed with its own bespoke animations, custom themes, and immersive sound effects (SFX) tailored to the event.
  • Live Countdowns: Real-time event countdowns and embedded Google Maps integration.

🚀 The Technology

InByte is built on a modern, robust full-stack architecture designed for a seamless user experience and strict data ownership.

  • Cloud Database & Auth: Powered by a secure Firebase Firestore database and authenticated Google user profiles, giving you a private dashboard to track your invites.
  • Secure Media Storage: Integrated with reliable iCloud image storage to safely host custom client photos uploaded to invitations.
  • Custom Web Components: Built using vanilla JavaScript and modern CSS to create a lightweight, blazing-fast responsive layout that seamlessly supports light and dark modes.
